# POOL PINUPS — CLAUDE DESIGN BRIEF

## PROJECT OVERVIEW

Pool Pinups is a fantasy STL Kickstarter project for 3D printable pinup miniatures.

The main concept is:

> Backers collaboratively create the next fantasy pinup character through community voting.

The experience must feel:
- premium,
- immersive,
- interactive,
- dark fantasy,
- elegant,
- collectible.

This is NOT a generic SaaS dashboard.
This is NOT a corporate voting platform.

The website should feel like:
- a premium fantasy event,
- a collector experience,
- a magical workshop where the next heroine is forged by the community.

---

# GENERAL VISUAL DIRECTION

## STYLE

Dark fantasy mixed with modern premium UI.

Visual references:
- fantasy card games,
- dark RPG interfaces,
- Diablo UI inspiration,
- elegant gothic fantasy,
- modern Kickstarter presentation pages.

Avoid:
- corporate SaaS style,
- flat startup design,
- childish fantasy,
- cartoon UI,
- generic bootstrap appearance.

---

# COLOR PALETTE

Primary colors:
- matte black
- dark charcoal
- deep crimson
- dark wine red
- antique gold

Accent colors:
- pale ivory
- silver
- subtle purple glow

Avoid:
- bright saturated colors,
- neon cyberpunk,
- pure white backgrounds.

---

# TYPOGRAPHY

Headers:
- elegant fantasy serif
- premium medieval-inspired typography

Body:
- modern readable sans-serif

The typography must feel:
- premium,
- collectible,
- immersive.

---

# UI STYLE

The UI should include:
- soft glow effects,
- elegant borders,
- fantasy card frames,
- subtle texture overlays,
- decorative separators,
- premium hover animations.

The interface must remain:
- clean,
- readable,
- modern,
- responsive.

Avoid excessive ornamentation.

# MAIN PAGES TO DESIGN

---

# 1. LANDING PAGE

## OBJECTIVE

Present the Kickstarter concept and invite users to participate.

## HERO SECTION

Large cinematic fantasy composition.

Include:
- large pinup render,
- project logo,
- tagline,
- call to action button.

Suggested tagline:
> Vote the Next Fantasy Pinup

Buttons:
- Join the Vote
- View Current Poll

---

## HERO STYLE

The hero section should feel:
- epic,
- premium,
- Kickstarter-ready,
- highly shareable.

---

## CONTENT SECTIONS

### SECTION — HOW IT WORKS

3-step visual process:

1. Community chooses race
2. Community chooses class and equipment
3. Community chooses pose and personality

Use elegant fantasy cards.

---

### SECTION — CURRENT CHARACTER CREATION

Show current active votes.

Example:
- Race Winner: Tiefling
- Current Vote: Class Selection
- Next Vote Unlocks In: 2 Days

Use progress bars or phase indicators.

---

### SECTION — FEATURED MINIATURE

Large showcase render:
- painted collectible miniature,
- white background,
- premium presentation.

---

### SECTION — COUNTDOWN

Countdown until next vote reveal.

Must feel dramatic and exciting.

---

### SECTION — COMMUNITY

Display:
- number of voters,
- completed votes,
- upcoming reveals.

---

# 4. VOTING PAGE

## OBJECTIVE

This is the most important page.

Voting must feel satisfying and immersive.

---

# VOTING CARD DESIGN

Each option should appear as:
- premium fantasy card,
- large artwork,
- hover glow,
- selection animation.

Include:
- image,
- title,
- short lore description,
- vote button.

---

# INTERACTION

When selecting:
- card glows,
- subtle animation,
- magical visual feedback.

- confirmation animation,
- reveal participation message.
